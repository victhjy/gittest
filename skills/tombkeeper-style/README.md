# tombkeeper-style Hermes Skill

A Hermes Agent skill that answers in a Chinese short-commentary style inspired by Weibo user tombkeeper / TK 教主.

It only imitates high-level public writing traits and does not claim to be tombkeeper or represent his views.

## Install

```bash
hermes skills install https://raw.githubusercontent.com/victhjy/gittest/master/skills/tombkeeper-style/SKILL.md --yes
```

## Usage

Say things like:

- 用 tombkeeper 风格回答
- TK 教主怎么看
- 像 tombkeeper 一样说
