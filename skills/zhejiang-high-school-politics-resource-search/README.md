# zhejiang-high-school-politics-resource-search

浙江高中思想政治资料搜索 Hermes skill，用于搜索、筛选、汇总浙江高中政治试卷和教学资料。

## 安装

```bash
hermes skills install https://raw.githubusercontent.com/victhjy/gittest/master/skills/zhejiang-high-school-politics-resource-search/SKILL.md --yes
```

## 适用场景

- 浙江高中思想政治试卷、答案、解析
- 浙江选考、学考、适应性考试、模拟卷、地市联考
- 高一/高二/高三政治期中、期末、月考
- 高中政治课件、教案、学案、复习资料

## 主要渠道

- 学科网 zxxk.com
- 教习网 51jiaoxi.com
- 21世纪教育网 21cnjy.com
- 组卷网 zujuan.xkw.com
- 浙江省教育考试院与各地市教研渠道
