# 浙江高中政治资料搜索 Skill

用户要找：
- 浙江高中思想政治/高中政治试卷、答案、解析
- 浙江选考、学考、适应性考试、模拟卷、联考、期中/期末卷
- 高一/高二/高三政治课件、教案、学案、复习资料
- 各地市：杭州、宁波、温州、绍兴、金华、台州、湖州、嘉兴、衢州、丽水、舟山的高中政治资料

## 优先渠道

### 1. 学科网 zxxk.com
定位：试卷质量和更新速度最好，适合找浙江地市联考、名校联盟卷、精品解析。

搜索词：
- `高中思想政治 浙江 试卷`
- `浙江 高三 思想政治 选考 适应性考试`
- `浙江 强基联盟 思想政治`
- `浙江 台州 温州 金华 丽水 思想政治 期末`

筛选：高中 → 思想政治 → 试卷/试题 → 浙江 → 最新。

### 2. 教习网 51jiaoxi.com
定位：覆盖面大，能直接按高中/政治/浙江/真题筛选，适合补漏和找可预览资料。

实测入口：在首页搜索 `高中政治 浙江 试卷`，页面会自动筛到：高中、政治/道德与法治、浙江省、真题。实测约有数千条结果，含：
- 浙江省普通高中政治学业水平诊断性/适应性考试
- 2024年高考政治试卷（浙江）
- 浙江各地高一高二高三期中期末、联考卷

### 3. 21世纪教育网 21cnjy.com
定位：课件、教案、学案、试卷兼有；适合找免费/普通资源和同步教学资料。

搜索词：
- `高中思想政治 浙江 试卷`
- `浙江省 高中 思想政治 课件`
- `浙江 高一 思想政治 必修 期中`

筛选：高中 → 思想政治 → 试卷/课件/教案 → 浙江省 → 按发布时间。

### 4. 组卷网 zujuan.xkw.com
定位：按题型、知识点、难度组卷，适合老师二次出卷；与学科网体系相关。

搜索词：

## 搜索策略

1. 先按年份搜：`2026 浙江 高三 思想政治 适应性考试 试题`。
2. 再按地市搜：`2026 温州 高三 思想政治 二模`、`2026 台州 高三 思想政治 教学质量评估`。
3. 再按联盟搜：`浙江强基联盟 思想政治`、`浙里特色联盟 思想政治`、`环大罗山联盟 思想政治`。
4. 最后按年级/考试类型补齐：高一/高二 + 期中/期末/月考/学考。

## 质量判断

优先级：
1. 官方/教研室/考试院发布
2. 学科网精品解析/名校联考
3. 教习网可预览整卷
4. 21世纪教育网近期资料
5. 文库类搬运资源

检查项：
- 年份是否最新
- 是否浙江卷/浙江地市卷
- 是否含答案和解析
- 是否匹配统编版高中思想政治教材
- 是否是高中政治，避免混入初中道德与法治
- 是否可下载、可预览、需会员
